AERO Hypercar ArchitectureA lightweight, vanilla front-end web application for exploring performance metrics, aerodynamic specifications, and market allocations of world-class hypercars. Built with pure HTML, CSS, and JavaScript without external framework dependencies.   Key FeaturesFleet Collection: Interactive grid displaying hypercar models with modal popups for detailed telemetry data.   Telemetry Comparison Engine: Side-by-side spec comparisons with relative percentage performance bars across power, top speed, and downforce.   Valuation Matrix: Dynamic pricing table featuring live toggling between Standard MSRP and Aerodynamic Track Pack pricing.   Constellation Canvas: Custom HTML5 Canvas rendering an animated interactive background particle system.   Scroll Animations: Smooth intersection-observer based scroll reveals paired with glassmorphism styling.   Project Structureindex.html: Primary landing page showcasing the vehicle collection and spec modal overlay.   compare.html: Dual-vehicle comparison interface for side-by-side telemetry evaluation.   pricing.html: Valuation matrix with dynamic track package price switching.   style.css: Dark-mode glassmorphism styling, responsive layouts, and design tokens.   script.js: Particle canvas loop, modal handling, vehicle dataset, and comparison logic.   Getting StartedClone the repository to your local machine.Open index.html in any modern web browser.   No build tools, package installations, or local server setups are required.Tech StackHTML5 and CSS3Vanilla JavaScript (ES6+)HTML5 Canvas API
