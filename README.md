#Aero
AERO Hypercar ArchitectureA lightweight, front-end web application for exploring telemetry data, aerodynamic specs, and market allocations for hypercars. Built with modern HTML, CSS, and vanilla JavaScript without external dependencies.   FeaturesFleet Collection: Browse hypercar models with interactive modal overlays displaying peak power, acceleration, top speed, and downforce telemetry.   Telemetry Comparison: Compare two hypercars side-by-side with dynamic animated performance bar charts.   Valuation Matrix: Interactive pricing schedule featuring live switching between standard MSRP and track pack options.   Constellation Background: Custom HTML5 canvas particle system with dynamic node connections.   Responsive Design: Dark glassmorphic interface with scroll reveal effects and clean mobile support.   File Overviewindex.html - Primary landing page showcasing the hypercar collection grid and specification modal.   compare.html - Dual-vehicle comparison interface with dynamic spec meters.   pricing.html - Interactive price chart with track package pricing toggle.   style.css - Custom styling, glassmorphism UI, grid layouts, and design variables.   script.js - Dynamic modal logic, comparison bar calculations, price toggles, and particle canvas animation.   Setup and UsageClone or download this repository.Open index.html in any web browser.   No build tools, package installations, or local server setups required.Tech StackHTML5   CSS3 (Flexbox, CSS Grid, Custom Variables)   Vanilla JavaScript (ES6+, HTML5 Canvas API)
